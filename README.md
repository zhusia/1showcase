# 1ShowcaseTool

Click through your app once and get a walkthrough.

Open-source Electron app that records a click-through of your product and turns
it into a polished, interactive walkthrough/guide — with annotations, captions,
voiceover, and video export.

## Open-source build

This is the **fully unlocked** open-source build. The previous commercial
licensing (LemonSqueezy) and entitlement gate are removed:

- No license key is required.
- All Pro features are available to everyone (no watermarks, no guide limits,
  full customization).
- No calls to `store.stoicsoft.com` or `api.lemonsqueezy.com`.

The code in this repository is a build of the desktop app source
(compiled output). It is published for reference and self-hosting.

## Running

```bash
npm install
npm start
```

Requires Node.js >= 20 and Electron.

## Features

- One-click recording of a click-through, in a real browser session
- Annotation and redaction tools (passwords/credentials never leak)
- AI guide narration (BYO OpenAI / Anthropic / Gemini API keys)
- Captions, music, studio moods
- Export to MP4 / APNG / PPTX / PDF / SCORM, or share over your local network
